# RBX Explorer на Android

Приложение для телефона, которое открывает файлы Roblox (`.rbxl`, `.rbxm`,
`.rbxlx`, `.rbxmx`) **без 3D-мира**: только иерархия Explorer, свойства
объектов и редактор скриптов. Оформление — Material 3 в приглушённых
шалфейно-зелёных тонах, есть светлая и тёмная темы.

Логика написана на Rust (`crates/rbx_explorer`) поверх парсеров rbx-native
(`rbx_dom`, `rbx_binary`, `rbx_xml`, `rbx_reflection`). Она собирается в
WebAssembly, а Kotlin-приложение вокруг неё (`MainActivity.kt`) даёт ей то,
чего у страницы нет: системный выбор файлов, запись обратно в файл,
список недавних, цвет системных панелей и кнопку «назад».

## Что умеет

- **Открытие.** Кнопка «Открыть место или модель» вызывает системный выбор
  файлов. Можно открыть файл и из файлового менеджера, Telegram или Drive
  через «Открыть с помощью» / «Поделиться».
- **Недавние.** Файлы, открытые через выбор, попадают на главный экран.
- **Explorer.** Сервисы идут в том же порядке и с теми же иконками, что в
  Studio. Узлы разворачиваются, есть поиск по имени и классу, а вкладка
  «Скрипты» показывает плоский список всех скриптов.
- **Свойства.** Сгруппированы как в Studio: «Данные», «Внешний вид»,
  «Поведение» и т.д. Цвета показаны образцами, Enum — именами, ссылки на
  объекты кликабельны.
- **Редактор скриптов.**
  - Подсветка Luau и номера строк.
  - Отмена и повтор.
  - Поиск и замена, с учётом регистра или без.
  - Переход к строке и автоотступ.
  - Ряд клавиш над клавиатурой: Tab, скобки, `=`, `.`, `:` и другие.
  - Размер шрифта 9–24 px.
- **Сохранение.**
  - «Сохранить» записывает файл обратно в его формате, если источник это
    разрешает.
  - Иначе, или через «Сохранить копию…», файл создаётся в выбранной папке:
    бинарный или XML.
  - При выходе с несохранёнными правками приложение спросит, что с ними
    делать.

Чего нет (и не задумывалось): рендера мира, редактирования свойств, кроме
`Source`, и вставки или удаления объектов.

## Сборка

APK собирает CI: `.github/workflows/android-explorer.yml`. Зелёный прогон
оставляет в артефактах `app-debug.apk` (для `adb install`) и подписанный
`rbx-explorer-ci-release.apk`.

Локально:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version <версия wasm-bindgen из Cargo.lock> --locked
./scripts/build-explorer.sh          # → crates/rbx_explorer/web/pkg
cd packaging/android-explorer
./gradlew assembleDebug              # → app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK 35. `syncWebAssets` перед сборкой копирует
страницу и `pkg/` в assets.

Ту же страницу можно открыть и в браузере на компьютере: удобно для
отладки. Файлы можно перетаскивать в окно, а сохранение работает как
скачивание:

```sh
python3 -m http.server -d crates/rbx_explorer/web 8080
```

## Устройство

- Страница отдаётся из APK по адресу
  `https://appassets.androidplatform.net/web/…`. Это перехват запросов
  WebView, в сеть ничего не уходит.
- Открытый файл страница забирает с `/doc/current`.
- Мост `window.Android` и функции страницы `rbxOpenFromHost`, `rbxSaved`,
  `rbxBack`, `rbxRecentsChanged` описаны в
  `crates/rbx_explorer/web/index.html` и `MainActivity.kt`.
- Иконки — Material Symbols Rounded (Apache-2.0), см.
  `crates/rbx_explorer/LICENSE-MaterialSymbols.txt`. Шрифт кода — JetBrains
  Mono (OFL).
